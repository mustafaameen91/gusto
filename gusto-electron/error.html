خطأ في الاتصال بالخادم

لا يمكن الاتصال بخادم التطبيق

📋 يرجى التأكد من:

  1. تشغيل خادم الـ Backend على المنفذ 3000
  2. تشغيل خادم الـ Frontend على المنفذ 8080

🚀 أوامر التشغيل:

Backend:
cd gusto-backend && npm start
Frontend:
cd gusto-frontend && npm run dev

بعد تشغيل الخوادم، قم بإعادة تشغيل التطبيق
